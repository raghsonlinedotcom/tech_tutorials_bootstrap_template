Introduction to REST Assured

REST Assured is a Java-based DSL (Domain-Specific Language) for simplifying the testing of RESTful web services. It brings the simplicity of dynamic languages (Ruby, Groovy) into the Java domain, making HTTP request crafting and response validation expressive and readable.

What is REST Assured?

REST Assured was created by Johan Haleby and first released in 2010. The latest major version, REST Assured 6.0.0 (released December 2025), raises the baseline to Java 17+, upgrades to Groovy 5, and adds Spring 7 + Jackson 3 support.

  • BDD-Style Syntax: Uses a Given-When-Then pattern that reads like a specification
  • Fluent API: Chainable methods for request building and response validation
  • JSON/XML Support: Built-in JsonPath and XmlPath for response parsing
  • Authentication: Supports Basic, Digest, OAuth 1.0/2.0, CSRF tokens
  • Schema Validation: JSON Schema and XML Schema/DTD validation
  • Spring Integration: Native support for Spring MockMvc and WebTestClient
Key Insight: REST Assured follows the BDD (Behavior-Driven Development) pattern: given() sets up the request, when() performs the action, and then() validates the response.

First Glimpse

import static io.restassured.RestAssured.*;
import static org.hamcrest.Matchers.*;

// BDD-style API test
given()
    .baseUri("http://localhost:8080")
    .header("Content-Type", "application/json")
    .body("{\"name\": \"Laptop\", \"price\": 999.99}")
.when()
    .post("/api/products")
.then()
    .statusCode(201)
    .body("name", equalTo("Laptop"))
    .body("price", equalTo(999.99f));

Advantages & Disadvantages

Advantages

Readable BDD Syntax

Given-When-Then style makes tests self-documenting. Even non-developers can understand what the test validates.

Powerful JSON/XML Parsing

Built-in GPath-based JsonPath and XPath for navigating deeply nested responses without external libraries.

Authentication Support

Out-of-the-box support for Basic, Digest, Form, OAuth 1.0, OAuth 2.0, and CSRF token handling.

Spring Integration

Native modules for Spring MockMvc and WebTestClient allow testing without starting a real server.

Schema Validation

Validate response structures against JSON Schema, XML Schema, or DTD definitions for contract testing.

Disadvantages

Java-Only

Limited to the JVM ecosystem. Teams using Python, Go, or Node.js need alternative tools (requests, supertest).

Startup Overhead

Integration tests with @SpringBootTest load the full application context, which can be slow for large apps.

Groovy Dependency

REST Assured depends on Groovy for its internal DSL, which adds JAR size and may conflict with other Groovy versions.

No Built-in Retry

Does not provide built-in request retry or polling mechanisms. Requires custom implementation or external libraries.

Limited Async Support

Primarily synchronous. Testing async endpoints (WebSockets, SSE) requires additional tooling.

Practical Use Cases

REST Assured excels in scenarios requiring automated validation of REST APIs.

Functional API Testing

Validate: CRUD operations, business logic, error handling, pagination, and filtering.

Example: E-commerce product catalog API

Contract Testing

Validate: API response structures against JSON Schema to ensure backward compatibility.

Example: Microservice API contracts

Security Testing

Validate: Authentication flows, authorization rules, token handling, and CORS policies.

Example: OAuth2-protected banking API

Integration Testing

Validate: End-to-end flows with real databases (via TestContainers) and downstream services.

Example: Order management with DB + messaging

Regression Testing

Validate: Automated suites in CI/CD to catch regressions on every commit.

Example: Jenkins/GitHub Actions pipeline

Data-Driven Testing

Validate: Same endpoint with multiple data sets using JUnit 5 @ParameterizedTest.

Example: Validation rules across edge cases

REST Assured DSL & Features

Complete reference for REST Assured's fluent BDD-style DSL.

given() - Request Configuration

import static io.restassured.RestAssured.*;

// Headers and Content-Type
given()
    .header("Authorization", "Bearer eyJhbGci...")
    .contentType("application/json")
    .accept("application/json")

// Query and Path Parameters
    .queryParam("page", 1)
    .queryParam("size", 10)
    .pathParam("id", 42)

// Request Body (JSON)
    .body("""
        {
            "name": "Wireless Mouse",
            "category": "Electronics",
            "price": 29.99,
            "stock": 150
        }
        """)

// Authentication
    .auth().basic("admin", "password")
    // OR .auth().oauth2("access_token")
    // OR .auth().preemptive().basic("user", "pass")

// Logging
    .log().all()  // Log entire request

.when()
    .post("/api/products")
.then()
    .log().ifError()  // Log only on failure
    .statusCode(201);

when() - HTTP Methods

// GET with query parameters
given()
    .queryParam("category", "Electronics")
.when()
    .get("/api/products")
.then()
    .statusCode(200)
    .body("size()", greaterThan(0));

// POST with JSON body
given()
    .contentType("application/json")
    .body(productJson)
.when()
    .post("/api/products")
.then()
    .statusCode(201);
// PUT (full update)
given()
    .contentType("application/json")
    .body(updatedProductJson)
.when()
    .put("/api/products/{id}", 42)
.then()
    .statusCode(200);

// DELETE
when()
    .delete("/api/products/{id}", 42)
.then()
    .statusCode(204);

// PATCH (partial update)
given()
    .contentType("application/json")
    .body("{\"price\": 19.99}")
.when()
    .patch("/api/products/{id}", 42)
.then()
    .statusCode(200);

then() - Response Validation

// Status code and content type
.then()
    .statusCode(200)
    .contentType("application/json")

// Body assertions with Hamcrest matchers
    .body("name", equalTo("Laptop"))
    .body("price", greaterThan(500.0f))
    .body("categories", hasSize(3))
    .body("categories", hasItem("Electronics"))
    .body("tags", containsInAnyOrder("sale", "new", "featured"))

// Nested JSON navigation
    .body("address.city", equalTo("Mumbai"))
    .body("orders[0].total", equalTo(1499.99f))
    .body("orders.findAll { it.total > 100 }.size()", greaterThan(0))

// Header assertions
    .header("X-Total-Count", "42")
    .header("Cache-Control", containsString("no-cache"))

// Response time
    .time(lessThan(3000L))  // milliseconds

// JSON Schema validation
    .body(matchesJsonSchemaInClasspath("schemas/product-schema.json"));

Extracting Response Data

// Extract single value
String productName = given()
    .when().get("/api/products/1")
    .then().statusCode(200)
    .extract().path("name");

// Extract entire response
Response response = given()
    .when().get("/api/products")
    .then().statusCode(200)
    .extract().response();

int statusCode = response.getStatusCode();
String body = response.getBody().asString();
String header = response.getHeader("Content-Type");

// Extract as POJO (Java Object)
Product product = given()
    .when().get("/api/products/1")
    .then().statusCode(200)
    .extract().as(Product.class);

// Extract list of objects
List<Product> products = given()
    .when().get("/api/products")
    .then().statusCode(200)
    .extract().jsonPath().getList(".", Product.class);

Filters & Logging

// Global configuration (in @BeforeAll)
RestAssured.baseURI = "http://localhost:8080";
RestAssured.basePath = "/api";
RestAssured.filters(new RequestLoggingFilter(), new ResponseLoggingFilter());

// Request specification reuse
RequestSpecification requestSpec = new RequestSpecBuilder()
    .setBaseUri("http://localhost:8080")
    .setBasePath("/api")
    .setContentType("application/json")
    .addHeader("Authorization", "Bearer token123")
    .build();

// Response specification reuse
ResponseSpecification responseSpec = new ResponseSpecBuilder()
    .expectStatusCode(200)
    .expectContentType("application/json")
    .build();

// Usage
given()
    .spec(requestSpec)
.when()
    .get("/products")
.then()
    .spec(responseSpec)
    .body("size()", greaterThan(0));

        existing.setPrice(updatedProduct.getPrice());
        existing.setStock(updatedProduct.getStock());

import org.springframework.http.HttpStatus;

import org.springframework.web.bind.annotation.*;
import java.time.LocalDateTime;
import java.util.*;
import java.util.stream.Collectors;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ProductNotFoundException.class)
    public ResponseEntity<Map<String, Object>> handleNotFound(
            ProductNotFoundException ex) {
        Map<String, Object> error = new LinkedHashMap<>();
        error.put("timestamp", LocalDateTime.now().toString());
        error.put("status", 404);
        error.put("error", "Not Found");
        error.put("message", ex.getMessage());
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(error);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidation(
            MethodArgumentNotValidException ex) {
        Map<String, Object> error = new LinkedHashMap<>();
        error.put("timestamp", LocalDateTime.now().toString());
        error.put("status", 400);
        error.put("error", "Validation Failed");

        List<String> messages = ex.getBindingResult()
            .getFieldErrors().stream()
            .map(fe -> fe.getField() + ": " + fe.getDefaultMessage())
            .collect(Collectors.toList());
        error.put("messages", messages);

        return ResponseEntity.badRequest().body(error);
    }
}

import org.springframework.boot.test.web.server.LocalServerPort;
import org.springframework.test.context.DynamicPropertyRegistry;
import org.springframework.test.context.DynamicPropertySource;
import org.testcontainers.containers.PostgreSQLContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;

import static io.restassured.RestAssured.*;
import static org.hamcrest.Matchers.*;

@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@Testcontainers
@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
@DisplayName("Product API Container Tests (TestContainers + PostgreSQL)")
class ProductApiContainerTest {

    @Container
    static PostgreSQLContainer<?> postgres =
        new PostgreSQLContainer<>("postgres:16-alpine")
            .withDatabaseName("inventory_test")
            .withUsername("testuser")
            .withPassword("testpass");

    @LocalServerPort
    private int port;

    @DynamicPropertySource
    static void configureProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);
        registry.add("spring.datasource.username", postgres::getUsername);
        registry.add("spring.datasource.password", postgres::getPassword);
        registry.add("spring.datasource.driver-class-name",
                      () -> "org.postgresql.Driver");
        registry.add("spring.jpa.database-platform",
                      () -> "org.hibernate.dialect.PostgreSQLDialect");
        registry.add("spring.jpa.hibernate.ddl-auto", () -> "create-drop");
    }

    @BeforeEach
    void setUp() {
        RestAssured.port = port;
        RestAssured.basePath = "/api/products";
    }

    @Test
    @Order(1)
    @DisplayName("PostgreSQL container is running")
    void containerIsRunning() {
        Assertions.assertTrue(postgres.isRunning(),
            "PostgreSQL container should be running");
    }

    @Test
    @Order(2)
    @DisplayName("CRUD operations on real PostgreSQL via TestContainers")
    void shouldPerformCrudOnPostgres() {
        // CREATE
        String body = """
            {
                "name": "Server Rack Unit",
                "description": "42U rack for data center",
                "category": "Infrastructure",
                "price": 2499.99,
                "stock": 5
            }
            """;

        Integer createdId =
            given()
                .contentType(ContentType.JSON)
                .body(body)
            .when()
                .post()
            .then()
                .statusCode(201)
                .body("name", equalTo("Server Rack Unit"))
                .extract()
                .jsonPath().getInt("id");

        // READ
        given()
        .when()
            .get("/{id}", createdId)
        .then()
            .statusCode(200)
            .body("name", equalTo("Server Rack Unit"))
            .body("price", equalTo(2499.99f));

        // UPDATE
        String updateBody = """
            {
                "name": "Server Rack Unit Pro",
                "description": "48U rack for enterprise DC",
                "category": "Infrastructure",
                "price": 3299.99,
                "stock": 3,
                "active": true
            }
            """;

        given()
            .contentType(ContentType.JSON)
            .body(updateBody)
        .when()
            .put("/{id}", createdId)
        .then()
            .statusCode(200)
            .body("name", equalTo("Server Rack Unit Pro"))
            .body("price", equalTo(3299.99f));

        // DELETE
        when()
            .delete("/{id}", createdId)
        .then()
            .statusCode(204);

        // VERIFY DELETED
        when()
            .get("/{id}", createdId)
        .then()
            .statusCode(404);
    }
}

Source Code Explanations

Key Decisions
  • spring-boot-starter-parent 3.4.1: Manages Spring Boot dependency versions, provides Maven plugin defaults, and sets Java 17 as baseline.
  • REST Assured 6.0.0: The latest major version requiring Java 17+. Uses Groovy 5 internally and supports Spring 7 + Jackson 3.
  • TestContainers 2.0.3: The junit-jupiter module enables @Testcontainers and @Container annotations. The postgresql module provides the PostgreSQL container.
  • H2 + PostgreSQL: H2 for fast dev/test cycles; PostgreSQL for production-realistic container tests.
  • maven-surefire-plugin 3.2.5: Ensures JUnit 5 tests are discovered and executed correctly.

Design Decisions
  • Jakarta Validation: @NotBlank, @DecimalMin, @Min annotations enforce constraints at the API layer before data hits the database.
  • BigDecimal for price: Avoids floating-point precision issues inherent in float/double for monetary values.
  • @PrePersist/@PreUpdate: JPA lifecycle callbacks automatically set createdAt/updatedAt timestamps.
  • Active flag: Enables soft-delete patterns rather than physical deletion.

Testing Pyramid
┌─────────────────────┐ │ Container Tests │ Slow, realistic │ (TestContainers) │ Real PostgreSQL ├─────────────────────┤ │ Integration Tests │ Medium speed │ (REST Assured+H2) │ Full API validation ├─────────────────────┤ │ Unit Tests │ Fast, isolated │ (Mockito+MockMvc) │ Controller logic └─────────────────────┘
  • Unit Tests (Mockito): Use @WebMvcTest + @MockBean to test controller logic in isolation. Service layer is mocked. No database, no network. Fastest.
  • Integration Tests (REST Assured + H2): Use @SpringBootTest(RANDOM_PORT) to start the full application. REST Assured sends real HTTP requests. H2 in-memory database provides fast data layer.
  • Container Tests (TestContainers): Use @Testcontainers to spin up a real PostgreSQL Docker container. Tests run against production-equivalent database. Slowest but most realistic.

Frequently Asked Questions

REST Assured sends real HTTP requests over the network to a running server, testing the full stack including serialization, filters, and error handling. MockMvc simulates the servlet container in-memory without network I/O, making it faster but less realistic.

You can also use REST Assured's spring-mock-mvc module to get the BDD syntax with MockMvc's speed.

REST Assured 6.0.0 raised the Java baseline to 17+ because:

  • It upgrades to Groovy 5, which requires Java 17
  • It adds Spring 7 support, which also requires Java 17+
  • Java 17 is the current LTS version with widespread adoption

If you need Java 11 support, use REST Assured 5.5.x.

TestContainers requires a Docker-compatible runtime. Alternatives include:

  • Colima (macOS) - Free, open-source Docker runtime
  • Podman (Linux/macOS) - Docker-compatible container engine
  • Rancher Desktop - Cross-platform Docker alternative
  • Testcontainers Cloud - Run containers in the cloud (no local Docker)

Set the DOCKER_HOST environment variable if using a non-default Docker socket.
