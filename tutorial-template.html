ASCII Diagrams

ASCII diagrams are perfect for representing simple structures and flows:

┌─────────────────────────────────────────┐ │ Application Layer │ │ ┌──────────┐ ┌──────────┐ │ │ │ Service │ │ Service │ │ │ │ A │ │ B │ │ │ └────┬─────┘ └─────┬────┘ │ └───────┼──────────────┼─────────────────┘ │ │ ▼ ▼ ┌─────────────────────────────────────────┐ │ Business Logic Layer │ │ ┌──────────────────────────────┐ │ │ │ Processing Engine │ │ │ └──────────────┬────────────────┘ │ └─────────────────┼───────────────────────┘ │ ▼ ┌─────────────────────────────────────────┐ │ Data Layer │ │ ┌──────────┐ ┌──────────┐ │ │ │ Database │ │ Cache │ │ │ └──────────┘ └──────────┘ │ └─────────────────────────────────────────┘

Usage: ASCII diagrams work well for system architecture, data flows, and hierarchical structures. They're accessible and render consistently across all platforms.

PlantUML Diagrams

For more complex diagrams, use PlantUML syntax with rendering services:

@startuml
actor User
participant "Web App" as Web
participant "API Server" as API
database "Database" as DB

User -> Web: Request Page
Web -> API: GET /api/data
API -> DB: Query
DB --> API: Results
API --> Web: JSON Response
Web --> User: Render Page
@enduml

Usage: PlantUML is excellent for sequence diagrams, class diagrams, and component diagrams. You can render them using the PlantUML server: http://www.plantuml.com/plantuml/

Code Examples

Syntax-highlighted code examples with copy functionality:

public class SpringBootApplication {
    
    @Autowired
    private UserRepository userRepository;
    
    public static void main(String[] args) {
        SpringApplication.run(SpringBootApplication.class, args);
    }
    
    @GetMapping("/users")
    public List<User> getAllUsers() {
        return userRepository.findAll();
    }
    
    @PostMapping("/users")
    public User createUser(@RequestBody User user) {
        return userRepository.save(user);
    }
}
Note: Make sure to handle exceptions properly in production code.

Overview

First complete release of the comprehensive Bootstrap technical tutorial template with all major components and features.

Features Implemented
Navigation & Layout
  • Sticky navigation bar with brand, links, dropdown, and search
  • Off-canvas sidebar for table of contents
  • Responsive mobile-first design
  • Fixed position theme controls
Theme System
  • Dark/Light theme toggle with smooth transitions
  • Three color flavors (Blue, Green, Purple) for light mode
  • CSS custom properties for easy theming
  • Bootstrap 5.3 native dark mode support
Content Components
  • Jumbotron/Hero section with gradient backgrounds
  • Carousel for visual content showcase
  • Tab groups (Overview, Diagrams, Code, Output)
  • Accordion for collapsible topics
  • Card layouts (3-column grid)
  • List groups (steps/checklist, resources)
Code & Technical Features
  • Prism.js syntax highlighting (200+ languages)
  • Copy-to-clipboard functionality for code blocks
  • Console output display with dark terminal theme
  • ASCII diagram support with monospace styling
  • PlantUML syntax examples
  • Configuration file examples
Interactive Elements
  • Form elements (text, select, textarea, checkbox, radio, range)

  • Alert messages (info, success, warning, danger)
  • Toast notifications
  • Tooltips with hover support
  • Popovers with click interaction
Technical Stack
  • Bootstrap: 5.3.2
  • Bootstrap Icons: 1.11.3
  • Prism.js: 1.29.0
  • JavaScript: Vanilla (no dependencies)
  • File Size: ~40KB uncompressed
  • Components: 14 major
  • Lines of Code: ~900
  • CDN Resources: 4
Known Limitations
  • Color Flavors: Only work in light mode (design choice)
  • PlantUML: Requires external rendering (not auto-generated)
  • Code Copy: Requires HTTPS or localhost for clipboard API
  • Theme Persistence: Session-only (no localStorage implementation)
