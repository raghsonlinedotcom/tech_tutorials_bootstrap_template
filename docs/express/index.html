Introduction

What is Express.js?

Express is a minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications.

Key Features
  • Robust routing
  • High performance
  • HTTP helpers (redirection, caching, etc)
  • View system supporting 14+ template engines
  • Content negotiation
  • Executable for generating applications
Why Express?
  • Minimal and unopinionated
  • Huge ecosystem of middleware
  • Industry standard (powers countless production apps)
  • Great documentation and community
  • Perfect for APIs and microservices
History

Express was created by TJ Holowaychuk in 2010. It quickly became the de facto standard web framework for Node.js and is now maintained by the Node.js Foundation.

Installation

Prerequisites

Before installing Express, make sure you have Node.js installed. Express requires Node.js 14.x or higher.

# Check if Node.js is installed
node --version
npm --version
Step 1: Create a Project Directory
mkdir my-express-app
cd my-express-app
Step 2: Initialize npm
# Create package.json with defaults
npm init -y
Step 3: Install Express
npm install express
Success! Express is now installed in your project.

Hello World - Your First Express Server

Create app.js

Create a file named app.js in your project root:

// Import express
const express = require('express');

// Create an Express application
const app = express();

// Define the port
const PORT = 3000;

// Define a route handler for the default home page
app.get('/', (req, res) => {
  res.send('Hello World!');
});

// Start the server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});
Run Your Server
node app.js
Server is running on http://localhost:3000
Test in Browser

Open your browser and navigate to http://localhost:3000. You should see:

Hello World!
Code Explanation

const express = require('express'); imports the Express module.

const app = express(); creates an Express application instance. This is your app object.

app.get('/', ...) defines a route handler for GET requests to the root URL (/). The callback function receives request (req) and response (res) objects.

app.listen(PORT, ...) binds and listens for connections on the specified port. The callback runs once the server starts.

Routing

What is Routing?

Routing refers to how an application's endpoints (URIs) respond to client requests. Express provides methods for each HTTP verb:

Basic Route Methods
// GET request
app.get('/users', (req, res) => {
  res.send('GET users');
});

// POST request
app.post('/users', (req, res) => {
  res.send('POST user');
});

// PUT request
app.put('/users/:id', (req, res) => {
  res.send(`PUT user ${req.params.id}`);
});

// DELETE request
app.delete('/users/:id', (req, res) => {
  res.send(`DELETE user ${req.params.id}`);
});
Route Parameters

Route parameters are named URL segments used to capture values:

// Single parameter
app.get('/users/:userId', (req, res) => {
  res.send(`User ID: ${req.params.userId}`);
});

// Multiple parameters
app.get('/users/:userId/books/:bookId', (req, res) => {
  res.json({
    userId: req.params.userId,
    bookId: req.params.bookId
  });
});
Example: GET /users/42/books/7 would return {"userId": "42", "bookId": "7"}
Query Parameters

Access query strings using req.query:

// URL: /search?name=john&age=30
app.get('/search', (req, res) => {
  res.json({
    name: req.query.name,  // "john"
    age: req.query.age     // "30"
  });
});
Response Methods
Method Description
res.send() Send a response of various types
res.json() Send a JSON response
res.status() Set response status code
res.redirect() Redirect to another URL
res.render() Render a view template

Middleware

What is Middleware?

Middleware functions are functions that have access to the request object (req), response object (res), and the next middleware function in the application's request-response cycle.

Request → Middleware 1 → Middleware 2 → Middleware 3 → Route Handler → Response
Application-Level Middleware

Runs for every request:

// Logger middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next(); // Pass control to next middleware
});

// All routes after this will be affected
app.get('/', (req, res) => {
  res.send('Home');
});
Built-in Middleware
// Parse JSON bodies
app.use(express.json());

// Parse URL-encoded bodies
app.use(express.urlencoded({ extended: true }));

// Serve static files
app.use(express.static('public'));
Third-Party Middleware

Popular middleware packages:

morgan - HTTP request logger
npm install morgan
const morgan = require('morgan');
app.use(morgan('dev'));
cors - Enable CORS
npm install cors
const cors = require('cors');
app.use(cors());
Custom Middleware Example
// Authentication middleware
const requireAuth = (req, res, next) => {
  const token = req.headers.authorization;
  
  if (!token) {
    return res.status(401).json({ error: 'No token provided' });
  }
  
  // Verify token (simplified)
  if (token === 'valid-token') {
    next(); // User is authenticated, proceed
  } else {
    res.status(403).json({ error: 'Invalid token' });
  }
};

// Protected route
app.get('/protected', requireAuth, (req, res) => {
  res.json({ message: 'This is protected data' });
});

Complete Example - Simple REST API

Here's a complete working example of a simple Task API:

const express = require('express');
const app = express();

// Middleware
app.use(express.json());

// In-memory data store
let tasks = [
  { id: 1, title: 'Learn Express', completed: false },
  { id: 2, title: 'Build an API', completed: false }
];

// GET all tasks
app.get('/api/tasks', (req, res) => {
  res.json(tasks);
});

// GET single task
app.get('/api/tasks/:id', (req, res) => {
  const task = tasks.find(t => t.id === parseInt(req.params.id));
  if (!task) {
    return res.status(404).json({ error: 'Task not found' });
  }
  res.json(task);
});

// POST create task
app.post('/api/tasks', (req, res) => {
  const task = {
    id: tasks.length + 1,
    title: req.body.title,
    completed: false
  };
  tasks.push(task);
  res.status(201).json(task);
});

// PUT update task
app.put('/api/tasks/:id', (req, res) => {
  const task = tasks.find(t => t.id === parseInt(req.params.id));
  if (!task) {
    return res.status(404).json({ error: 'Task not found' });
  }
  
  task.title = req.body.title || task.title;
  task.completed = req.body.completed ?? task.completed;
  res.json(task);
});

// DELETE task
app.delete('/api/tasks/:id', (req, res) => {
  const index = tasks.findIndex(t => t.id === parseInt(req.params.id));
  if (index === -1) {
    return res.status(404).json({ error: 'Task not found' });
  }
  
  tasks.splice(index, 1);
  res.status(204).send();
});

const PORT = 3000;
app.listen(PORT, () => {
  console.log(`Task API running on http://localhost:${PORT}`);
});
Testing with curl
# GET all tasks
curl http://localhost:3000/api/tasks

# POST new task
curl -X POST http://localhost:3000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"New Task"}'

# PUT update task
curl -X PUT http://localhost:3000/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"completed":true}'

# DELETE task
curl -X DELETE http://localhost:3000/api/tasks/1
